# Repository Agent Instructions

Read `README.md`, `docs/PROJECT_BRIEF.md`, and `docs/AGENT_WORKFLOW.md` before implementing changes.

## Non-negotiable constraints
- Build an authentic developer portfolio. Never invent contact information, social links, awards, metrics, user counts, testimonials, or production readiness.
- Treat every route as its own visual world. Do not apply one global aesthetic to every page.
- Preserve route discoverability and accessible navigation despite experimental navigation layouts.
- Use semantic HTML, keyboard-accessible controls, visible focus, sufficient contrast, and reduced-motion support.
- Keep secrets out of the repository and client bundle.
- Do not overwrite another agent's scope. Coordinate ownership before editing shared files.
- Do not claim a check passed unless it was actually run.
- Do not deploy until build and required quality checks pass, and verify the production URL.
